Sizzle & Serve — a fast-paced original cooking game. Run the lunch rush: take orders off the board, grill patties before they burn, chop tomatoes, stack each dish exactly to its recipe, and ring the serve bell before patience runs out. Rush hour pays double. Four recipes, two grill slots, a fryer, a chopping board, and a 150-second shift that ends when the timer hits zero.

## Run it

```sh
node main.ts
```

Or play it in a browser: serve `game/` with any static server and open `index.html`. Move with WASD or arrow keys, press E to grab and use stations, Q to serve at the window, or click a station to walk there.

## Play it

```sh
python3 -m http.server --directory game 8080
```
